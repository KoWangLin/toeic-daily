如何單獨使用？ (完全脫離 Gemini 運作)

此專案為 100% 獨立的 Single-File Web App，無需任何伺服器！

1 下載 HTML 檔案直接雙擊執行

RECOMMENDED

打卡紀錄、暗色主題、發音引擎與高頻題庫全整合在單一檔案中。直接下載儲存到電腦或手機，雙擊就能用 Chrome、Edge 或 Safari 開啟離線複習！

2 免費架設到手機主畫面 (GitHub Pages)

  1. 在 GitHub 建立一個公開 Repository（例如 toeic-daily）。
  2. 將下載的檔案命名為 index.html 上傳。
  3. 在 Settings > Pages 啟用部署，即可取得專屬網址，手機瀏覽器可「加入主畫面」當作專用 App 使用！

3 串接 Google 免費 Gemini API Key (可選)

前往 Google AI Studio (aistudio.google.com) 免費領取 API Key。填入下方後，每次點擊「AI 生成」將自動呼叫 Gemini 產出全新多益題目（儲存於本機 LocalStorage，不外洩）：

未填寫時將使用內建的高頻題庫。
